# V3.4.0 GitHub 并入与选中色修复

> 状态：已正式发布并提交

## 目标

把 2026-019-Studio工具箱的独立 GitHubConnection 模块（v1.0.2）整体并入 HistoryJanus 成为第三页面；按宿主《HistoryVulcan_UI风格与嵌入页面规范》修复项目总览深色模式行选中发白的问题，并让 github 页面全面合规；发布 3.4.0 小版本。

## 实现

- 源码并入（`b-Code-Studio/GitHub/`）：服务、模型、脱敏器、无 Shell 进程门面原样迁移，命名空间改为 `HistoryJanus.GitHub`；`ModuleInfo`/`ModuleInfoBase`、独立 manifest、`nuget.config` 退役。
- 配置同源：`RepositoryPathResolver`（旧 `OneHistoryStudio\settings.json` 直读）删除，服务构造改收 `Func<string>`，与项目库共用宿主设置的 `proj.barerepo`（默认 `HistoryVesta.git`）。
- 命令并入：`GitHubCommands` 改写为 Janus `RegisterAll`/`CommandDescriptor` 风格，`github.status`、`github.accounts`、`github.test` 全部只读、源 `module:HistoryJanus`，MCP 只读投影继续成立；登录/注销/提交身份/origin 修改维持仅限页面内经确认执行。
- 窗口注册：新增 `Id = "github"`、`Title = "github"`（短标题，避免标签过长）、右侧 `0.28`，宿主自动与 `projops` 并入右侧标签组；旧窗口 ID `github.account` 撤销。
- github 页面合规：根面 `Shell.Brush.Surface`/`TextPrimary`，全部硬编码色（`#555B63`、`#4B5563`）移除；三个 DataGrid 套用与项目操作页一致的表头/行/单元格样式（行选中 `AccentSoft`）；TabControl 沿用 Shell 模板不覆盖；删除底部状态行，错误与预览反馈改由对话框承载（与 3.3.1 收口决定一致）。
- 总览选中色修复：`WorktreeList` 的本地 `ItemContainerStyle` 曾整体替换宿主隐式样式（`Shell.Item.Base`，IsSelected→AccentSoft），深色模式回退系统白底。现改为自带 `GridViewRowPresenter` 的本地模板，选中 `AccentSoft`、悬停 `SurfaceHover`，浅色/深色即时跟随；不用 `BasedOn StaticResource` 是为了让页面在无宿主资源的模块冒烟环境仍可构造。
- 版本源、manifest 更新为 `3.4.0`；模块状态命令文案改为三个页面。
