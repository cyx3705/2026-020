# V3.5.0 指令集重构与 github 页深度合规

> 状态：已正式发布并提交

## 目标

1. 将 Janus 全部 34 条指令重构为 `janus.<类>.<方法>` 全小写三段式，取消独立 github 命令域，旧名一次作废。
2. 按宿主 UI 规范深度修复 github 页白按钮与白表格。
3. 产出跨模块《指令优化规范》供其他模块 AI 对齐。

## 指令映射

| 旧 | 新 |
| --- | --- |
| `HistoryJanus.Status` | `janus.status` |
| `proj.list/create/delete/tree/commit/push/commitall/pushall/open/scan/repair/note/config` | `janus.proj.<同名>` |
| `proj.metalist` / `proj.metaopen` | `janus.meta.list` / `janus.meta.open` |
| `proj.history` / `.show` / `.diff` | `janus.history.list` / `.show` / `.diff` |
| `proj.rollback` / `.reset` / `.forcepush` | `janus.history.rollback` / `.reset` / `.forcepush` |
| `git.rule.list/scan/review/sync/set/batch-set/remove` | `janus.gitrule.list/scan/review/sync/set/batchset/remove` |
| `github.status/accounts/test` | `janus.github.status/accounts/test` |
| `debug.logflood/sleep` | `janus.debug.logflood/sleep` |

实现要点：`ModuleInfo.CommandPrefix = "janus"`；`HistoryJanusCommands.status()` 小写方法名；五个注册文件与全部视图 `ExecuteAsync` 字面量同步；设置键（`proj.barerepo` 等）与窗口 ID 不改。

## github 页 UI

- 删除覆盖宿主隐式 `Shell.Button.Base` 的模块级 `Style TargetType="Button"`（白按钮根因）。
- 三个 DataGrid 补齐 `Surface` / `SurfaceAlt` / `Hairline` / `GridLinesVisibility` / `SelectionUnit`，与项目操作页 RuleGrid 一致。
