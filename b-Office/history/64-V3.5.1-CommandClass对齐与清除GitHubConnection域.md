# V3.5.1 CommandClass 对齐与清除 GitHubConnection 域

> 状态：已正式发布并提交

## 目标

1. 修正并入后残留的错误 `CommandClass`（`connection`/`account`/`git-rules`/`projects`/`status`），使宿主目录「类」过滤与命令名中间段一致。
2. 清除宿主 `%APPDATA%/OneHistoryStudio/Modules/GitHubConnection` 旧槽，避免 github 连接仍以独立「域」出现。

## 变更

| 命令族 | 旧 CommandClass | 新 CommandClass |
| --- | --- | --- |
| `janus.github.*` | `connection` / `account` | `github` |
| `janus.gitrule.*` | `git-rules` | `gitrule` |
| `janus.proj.*` | `projects` | `proj` |
| `janus.meta.*` | `projects` | `meta` |
| `janus.status` | `status` | `core` |

Contracts 新增：三段式命令的 `CommandClass` 必须等于中间段。
