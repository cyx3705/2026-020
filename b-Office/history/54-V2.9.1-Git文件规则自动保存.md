# V2.9.1 Git 文件规则自动保存

> 日期：2026-08-04
> 状态：正式发布与部署完成

## 目标

移除文件规则的独立“保存修改”动作，让表格编辑和新增规则在短暂防抖后自动批量保存；同时把“添加规则”移到
扩展名输入框所在行，减少规则操作条长度。OHS 提升为 `2.9.1`，AppShell 保持 `3.0.3`。

## 实现

- 删除 `SaveRuleButton` 与 `OnSaveRuleClick`。
- 使用单个 600ms `DispatcherTimer` 合并连续 Git/LFS/LF 属性变化；一次计时只提交一批有效脏行。
- 自动保存继续调用 `git.rule.batch-set` 的 `apply=false` 预览和 `apply=true` 应用，保留既有本机确认边界。
- 保存成功后接受当前快照，不强制重扫表格；覆盖率需要时由“刷新规则”统一重扫。
- 保存失败或取消确认时保留脏行；切换项目、刷新项目、刷新规则和删除规则前先尝试完成待保存批次，失败则
  阻止后续动作。
- 新增规则默认普通 Git，并进入同一自动保存队列；尚未落盘的草稿仍可直接删除。
- `PatternBox` 与 `AddRuleButton` 使用同一行两列布局；规则操作条只保留刷新、审查、同步基线和删除。
