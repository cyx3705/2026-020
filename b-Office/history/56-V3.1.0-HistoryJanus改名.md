## 指针修复方法

裸仓 `HistoryVesta.git` 登记约 29 个 worktree 的绝对路径。目录改名后按顺序重写：

1. 改 `2026-020-OneHistoryStudio` → `HistoryJanus`；
2. 改 `OneHistory-Projects.git` → `HistoryVesta.git`；
3. 改 `OneHistory-Projects` → `HistoryVesta`；
4. 重写 `HistoryVesta.git\worktrees\*\gitdir`、各 worktree `.git` 文件的 `gitdir:` 行、自定义 `worktree_paths.txt`；
5. 遗漏项以 `git worktree repair` 兜底；验证 `git worktree list` 与 `git status` 正常。

本次额外发现：裸仓开启 `extensions.worktreeConfig=true` 时，主 worktree 缺少 `config.worktree` 会导致 `git status` 报 "fatal: this operation must be run in a work tree"；补齐 `[core] bare = false` 后恢复。`branch_list.txt` 为手工维护的陈旧清单（止于 2026-011），与真实分支集已不一致，本次未改动。
