# OneHistoryStudio V2.1.1 · MCP 工具管理页与模块管理页

> 日期：2026-07-16 ｜ 性质：小版本升级（V2.1.0 → V2.1.1）｜ 状态：已交付并部署
> 边界：全部改动在 App 自由区（Views / Mcp / Git / 装配点），零框架改动，基线 0.4.2 未分叉

## 1. 一句话定义

给 MCP 服务和模块托管各配一个**管理页面**：能看清有哪些 MCP 工具并**编辑保存每个工具的
提示词**（客户端下次 tools/list 即生效）；能看清装载了哪些模块及各自注册的指令。

## 2. 新增功能

### 2.1 「MCP 工具」页（win.show name=mcp，默认顶部标签组）

| 区域 | 内容 |
|---|---|
| 工具清单 | 全部 MCP 工具：工具名 / 对应指令 / 标记（⚠危险拒绝 · ✎已自定义）/ 提示词首行；顶部搜索框即时过滤 |
| 详情编辑 | 灰色只读「指令自带说明」+ 可编辑「生效提示词」多行文本框 + **保存** / **恢复默认** |
| 工具条 | 刷新（mcp.schema）· 服务状态（mcp.status） |

### 2.2 提示词覆盖机制（新指令 `mcp.desc`）

```text
mcp.desc name=proj.list                    # 查看(默认说明 + 覆盖状态)
mcp.desc name=proj.list text="新提示词"    # 保存覆盖(上限 2000 字符)
mcp.desc name=proj.list reset=true         # 恢复指令自带 Summary
```

- 存储：main 库 `mcp_descriptions` 表（表窗口可查），跨重启持久。
- 合成位置：CommandSchemaExporter **导出读取侧**——保存后客户端下次 tools/list 即见新
  提示词，恢复默认同样即时，无需重启宿主或服务（每次现算零缓存，与热重载同律）。
- 页面按钮 = 组装 `mcp.desc` 指令经总线执行（架构不变量 1，控制台可见回显）；
  `mcp.*` 属硬排除域，提示词不可被 MCP 远端自改。

### 2.3 「模块管理」页（win.show name=modules，默认顶部标签组）

| 区域 | 内容 |
|---|---|
| 模块清单 | 名称 / 版本 / 暴露模式（全暴露·精准暴露）/ 指令数 / 来源文件 / 描述 |
| 指令明细 | 选中模块 → 其注册的全部指令（指令名/说明/示例），**双击行发 help** |
| 工具条 | 刷新 · 重载全部模块（module.reload）· 打开模块目录（module.open） |

### 2.4 面板合并（用户指定）

V2.0-M4 的 UI-12「模块管理」按钮面板（projmod.json）功能被本页完全覆盖，已移除：
装配点不再种子该面板，启动时一次性回收既有 `panels\projmod.json`（幽灵窗口经一次重启消失，
布局持久化既有行为）。项目操作 / 提交推送两块 JSON 面板保持不变。
