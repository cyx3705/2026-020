# V3.3.2 项目选择行收口与发布目录改名

> 状态：已正式发布并提交

## 目标

按用户截图反馈继续收口项目操作页：删除冗余的"当前项目"选择行；正式发布目录按 z 级命名规则由 `z-Package-HistoryJanus` 改名为 `z-HistoryJanus`。

## 实现

- 项目操作页（`ProjectOperationsView`）：
  - 删除"当前项目："行（`CurrentProjectBox` 组合框与"刷新"按钮），新建区收缩为单行"新项目名称 + 输入框 + 新建"。
  - 项目选择唯一真源收敛为共享 `ProjectSelectionState`（由项目总览页驱动）：`CurrentProjectName()` 改读共享选择，`ApplySharedSelectionAsync` 直接依据 `_projectNames` 校验并加载规则；`_suppressProjectSelection`、`RestoreProjectSelection`、ComboBox 事件链全部退役。
  - 脏规则守卫保持不变：切换目标被拒时把共享选择写回已加载项目，事件驱动二次同步。
- 发布目录改名：
  - `Publish-Janus.ps1` 正式目标改为 `z-HistoryJanus`；包内 API 文档子目录由 `package/` 改为 `docs/`，与 `z-HistoryVulcan` 布局惯例对齐；`Assert-ModulePackage` 文件集合同步。
  - `Test-QualityGate.ps1` 正式树边界检查（五类条目 + `docs/` 单一 API 文档）同步改名。
  - `.gitattributes` LFS 规则、`VersionProjection` 治理断言、README 与 b-Office 文档中的路径全部更新。
- 版本源、manifest 更新为 `3.3.2`；状态命令版本由程序集投影。
